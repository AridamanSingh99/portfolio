/Selected work

A background agent tidies up saved memories between sessions, while the main agent is idle.

Imagine an assistant remembers both “lives in Delhi” and “lives in Pune” after someone moves. Saving both notes leaves the next conversation open to a stale answer. AutoDream’s background pass merges repeated notes, updates outdated facts and removes trivial or contradicted entries. The aim is to give the next session a smaller, more useful set of memories to search.

Agent memory · Background processing

Follows a live conversation and surfaces the moments worth your attention.

A useful detail can disappear in a long conversation. Overheard uses a team of AI agents to follow the discussion, identify relevant information and deliver it as a short notification. The design challenge is deciding when a detail matters enough to interrupt someone.

Python · Multi-Agent · NLP

Turns a PDF into a study session with questions, summaries, quizzes and notes.

A reader can start with a question, explore the relevant material and then check their understanding with a quiz. The document stays at the center of the workflow, so asking a follow-up or making a note fits naturally into the same reading session.

Python · NLP · LLM

Brings recurring tasks, reminders and habit tracking into one desktop application.

Scheduling a task answers what comes next. Tracking a routine answers a different question: did I keep doing it? The project brings both views together in JavaFX, with SQLite storing the routine data between sessions.

Java · JavaFX · SQLite

Explores how a chatbot can carry context through a basic health-information conversation.

A follow-up question often makes sense only in light of the previous turn. This project uses Python, natural language processing and Flask to explore that interaction in a chat interface focused on general health information.

Python · NLP · Flask

Explores how copies of the same data behave across multiple machines.

If a record changes on one machine, what should a reader on another machine see? The project uses questions like this to explore replication, consistency and the trade-offs involved in choosing where a query runs.

Java · DBMS · Networking

/About me

I’m a Computer Science Engineering student specializing in Artificial Intelligence at Galgotias University. I enjoy turning ideas into reliable software, from tools that make documents easier to explore to applications that help people manage their routines.

/Why hire me

When something breaks, I get curious.

My first question is usually, “What can I try next?” I like taking a problem that feels too big, finding one piece I can test, and using what I learn to move forward. That’s what a positive mindset looks like to me on a difficult day.

AI makes it easy to generate an answer. I care about whether that answer still holds up when the document is long or the user has changed their mind. That question connects my PDF reader with AutoDream. On a team, I bring the same curiosity, a willingness to change my approach, and the patience to follow a problem through.
